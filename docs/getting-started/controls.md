# Controls

## Keyboard (default)

| Action | Player 1 | Player 2 |
|--------|----------|----------|
| Move left | `←` / `A` | `J` |
| Move right | `→` / `D` | `L` |
| Aim up | `↑` / `W` | `I` |
| Aim down | `↓` / `S` | `K` |
| Fire | `LCtrl` | `Enter` |
| Change weapon | `LShift` | `RShift` |
| Jump | `Space` | `RCtrl` |

### Global hotkeys

| Key | Action |
|-----|--------|
| `F2` | Toggle CRT scanline overlay |
| `Escape` | Return to menu (while playing) |

---

## Gamepad (gilrs)

Up to 2 gamepads are supported (any XInput / HID layout):

| Action | Button / Axis |
|--------|---------------|
| Move + Aim | Left stick or D-pad |
| Fire | RT (right trigger) or South button |
| Change weapon | LB (left bumper) or West button |
| Jump | B button or RB (right bumper) |

The first connected gamepad controls P1; the second controls P2.
